# deepseek-web-theme
【大肥鱼网页端皮肤】把 DSH 热门皮肤「虎鲸链路 / ORCA LINK」移植到 DeepSeek 官网的 Edge 扩展。基于官方设计令牌 1:1 重新实现：104 项 --dsw-* 逐值照搬，配色顺站点变量系统自动流入气泡、边框、侧栏与菜单；亮暗各一对 16:9 场景底图，640ms 交叉淡化，半透明底板让场景自然透出；全局直角契约；10 状态 × 8 帧动画，含 80 个逐帧质心补偿。另含图标蓝化与夜间选中会话淡金调整，并已移除网页版无意义的峰谷定价红绿灯。代码 MIT，美术资源 CC BY-NC-SA 4.0 禁止商用，署名一创上善、二创 Small-tailqwq。
